# The DEFINE Service & Partner Path

An interactive one-page site presenting the DEFINE service & partner path — a defence and dual-use innovation ecosystem in Riihimäki, Finland. Visitors choose their partner type (company/startup, established industry, R&D, public sector, or international) and walk through the five stages from first contact to continued cooperation.

## Live page

Once GitHub Pages is enabled for this repository, the page is available at:

**https://uman05.github.io/Define-Service-pathway-/**

## Running locally

Just open `index.html` in any browser — the page is fully self-contained (no build step, no dependencies).
